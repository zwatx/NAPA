# NAPA documentation

Start with the [examples](../examples/README.md) if you want running code. Start with
[Detection](detection.md) if you want to choose settings. The [API reference](api.md) is the lookup for every class,
method, and field.

- [Examples](../examples/README.md). No-camera quick start, images, webcam and video, calibrated poses, and the C API.
- [Detection](detection.md). Choosing settings, tuning, families, printing tags, and switching from `pupil_apriltags`.
- [Poses and filters](poses.md). Metric poses, covariances, WPILib pose estimators, and rolling-shutter cameras.
- [Camera calibration](calibration.md). Measuring a camera with a checkerboard.
- [Stereo rigs](stereo.md). One pose from two calibrated cameras.
- [Platforms](platforms.md). The C and C++ API, Android and Meta Quest, and building from source.
- [Measuring on your own footage](measuring.md). Scoring NAPA on images you label yourself.
- [How NAPA works](how-it-works.md). The pipeline, obstructions, and limits.
- [API reference](api.md). Every class, method, and field.
- [Benchmarks](../benchmarks/README.md). How the comparison with other detectors was built, and every result.
